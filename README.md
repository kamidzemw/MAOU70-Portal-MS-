# МАОУ СОШ №70 — портал

## Версия v16 — управление удалением пользователей

### Что добавлено
- Главный администратор может удалить любого ученика и любого администратора.
- Администратор с выданным правом `Может удалять пользователей` может удалять учеников и администраторов.
- Администратор без этого права не видит кнопки удаления и не сможет вызвать удаление напрямую: право проверяется на стороне Supabase.
- Только главный администратор может выдавать/забирать право `Может удалять пользователей`.
- Главный администратор всегда имеет это право.
- В профиле можно удалить собственный аккаунт, в том числе аккаунт администратора.

## Обновление Supabase
1. Открой Supabase → SQL Editor.
2. Выполни целиком файл `supabase.sql` из этой версии.
3. После успешного выполнения загрузи остальные файлы в GitHub Pages.

Важно: SQL добавляет колонку `profiles.can_delete_users`, RPC-функции управления правами и удаления аккаунтов, а также серверную защиту от самостоятельной выдачи права удаления обычным администратором.
